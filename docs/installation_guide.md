## 概述

本指南提供 Windows-User-Files-Mover 工具各版本的安装方法、配置步骤和环境要求。该工具提供三个版本：批处理版、Python版和EXE可执行文件版，满足不同用户的使用需求。

## 批处理版本安装

批处理版本是最简单的版本，无需安装即可使用。

### 安装步骤

1. **下载项目**
   - 访问项目GitHub页面：[https://github.com/sutchan/Windows-User-Files-Mover](https://github.com/sutchan/Windows-User-Files-Mover)
   - 点击 "Code" 按钮，选择 "Download ZIP"
   - 将ZIP文件下载到本地计算机

2. **解压文件**
   - 右键点击下载的ZIP文件
   - 选择 "全部解压缩"
   - 选择目标文件夹进行解压（建议路径不要包含中文）

3. **运行验证**
   - 打开解压后的文件夹
   - 找到 `Windows_UserFiles_Mover.bat` 文件
   - 右键点击该文件，选择 "以管理员身份运行"
   - 如果程序正常启动并显示主菜单，则安装成功

### 批处理版本特点

- **无需安装依赖**：使用Windows内置命令
- **轻量级**：文件体积小，启动快速
- **兼容性好**：支持所有现代Windows版本
- **无需额外配置**：开箱即用

## Python版本安装

Python版本提供图形用户界面，需要先安装Python环境。

### 安装步骤

1. **安装Python**
   - 访问Python官方网站：[https://www.python.org/downloads/windows/](https://www.python.org/downloads/windows/)
   - 下载Python 3.6或更高版本的安装程序（推荐Python 3.8+）
   - 运行安装程序
   - **重要**：勾选 "Add Python X.X to PATH" 选项
   - 点击 "Install Now" 完成安装

2. **验证Python安装**
   - 以管理员身份打开命令提示符
   - 执行命令：`python --version`
   - 如果显示Python版本号，则安装成功

3. **下载并解压项目文件**
   - 同批处理版本的下载和解压步骤

4. **运行程序**
   - 方法一：使用启动脚本
     - 找到 `run_python_version.bat` 文件
     - 双击运行该文件（会自动以管理员身份启动）
   - 方法二：手动运行
     - 以管理员身份打开命令提示符
     - 导航到程序所在目录
     - 执行命令：`python Windows_UserFiles_Mover.py`

### Python版本依赖

Python版本主要使用Python标准库，无需安装额外的第三方依赖：

- **tkinter**：用于图形界面（Python标准库的一部分）
- **os**：操作系统接口（Python标准库）
- **sys**：系统特定参数和函数（Python标准库）
- **subprocess**：子进程管理（Python标准库）
- **threading**：线程管理（Python标准库）
- **datetime**：日期和时间处理（Python标准库）
- **ctypes**：Python的外部函数库（Python标准库）

### 常见问题排查

如果Python版本无法启动，请检查以下几点：

1. **Python是否正确安装**：执行 `python --version` 确认
2. **PATH环境变量是否配置正确**：尝试在命令提示符中直接输入 `python`
3. **是否有足够权限**：确保以管理员身份运行
4. **tkinter是否可用**：某些精简版Python可能不包含tkinter

## EXE版本安装

EXE版本是Python版本的独立可执行文件打包版，无需安装Python环境。

### 获取EXE文件的方法

#### 方法一：使用预打包的EXE文件（如果提供）

如果项目发布了预编译的EXE版本，可以直接从发布页面下载。

#### 方法二：自行打包EXE文件

1. **准备环境**
   - 安装Python 3.6+环境（参见Python版本安装部分）
   - 安装PyInstaller：
     ```
     pip install pyinstaller
     ```

2. **使用打包脚本**
   - 以管理员身份运行 `build_exe_robust.bat` 文件
   - 等待打包过程完成
   - 打包后的EXE文件将位于 `dist` 文件夹中

3. **验证EXE文件**
   - 进入 `dist` 文件夹
   - 找到 `Windows_UserFiles_Mover.exe` 文件
   - 右键点击该文件，选择 "以管理员身份运行"
   - 如果程序正常启动，则打包成功

### EXE版本特点

- **独立可执行文件**：无需安装Python环境
- **便于分发**：适合在没有Python的计算机上使用
- **运行方式与Python版相同**：提供相同的图形界面
- **文件体积较大**：由于包含Python解释器和依赖库

## 系统要求

### 硬件要求

- **CPU**：1GHz或更高处理器
- **内存**：至少50MB可用内存
- **存储**：
  - 程序本身：约10MB
  - 工作空间：根据迁移文件大小而定，建议目标分区有足够空间

### 软件要求

| 版本 | 操作系统 | 其他要求 |
|------|----------|----------|
| 批处理版 | Windows 7/8/10/11 | ROBOCOPY命令（Windows Vista及以上版本默认包含） |
| Python版 | Windows 7/8/10/11 | Python 3.6或更高版本 |
| EXE版 | Windows 7/8/10/11 | 无特殊要求 |

### 权限要求

- **所有版本**：必须以管理员身份运行才能执行以下操作：
  - 创建目录联接(junction points)
  - 修改系统文件和文件夹
  - 访问和修改开始菜单数据库
  - 管理Windows资源管理器进程

## 环境变量配置

### Python版本的环境变量

如果手动运行Python版本，需要确保以下环境变量已正确配置：

1. **PATH**：包含Python安装目录
   - 例如：`C:\Users\用户名\AppData\Local\Programs\Python\PythonXX`
   - 例如：`C:\Users\用户名\AppData\Local\Programs\Python\PythonXX\Scripts`

2. **PYTHONPATH**（可选）：如果需要导入自定义模块

### 测试环境变量

1. 打开命令提示符
2. 执行以下命令检查Python环境：
   ```
   python --version
   ```
3. 执行以下命令检查pip环境：
   ```
   pip --version
   ```

## 安装后验证

### 批处理版本验证

1. 以管理员身份运行 `Windows_UserFiles_Mover.bat`
2. 验证主菜单是否正常显示
3. 选择 "4" 查看日志，确认日志功能正常
4. 选择 "0" 退出程序

### Python版本验证

1. 以管理员身份启动程序
2. 验证图形界面是否正常显示
3. 检查所有三个选项卡（文件迁移、开始菜单备份、开始菜单还原）是否可访问
4. 验证日志区域是否正常工作

### 功能测试

建议在实际使用前进行简单的功能测试：

1. **开始菜单备份测试**：执行一次开始菜单备份操作，确认备份文件生成
2. **小型文件迁移测试**：选择一个较小的用户文件夹（如Links）进行迁移测试
3. **开始菜单还原测试**（可选）：在备份后进行还原操作，确认功能正常

## 升级指南

### 从旧版本升级

1. **备份数据**：确保重要数据已备份
2. **下载新版本**：从GitHub下载最新版本的项目文件
3. **替换旧文件**：将新版本的文件复制到旧版本的文件夹中，替换同名文件
4. **验证升级**：运行程序并检查版本号是否更新

### 升级注意事项

1. 升级不会影响之前迁移的文件或创建的目录联接
2. 升级不会删除之前的备份文件
3. 建议在升级前记录当前程序版本号

## 卸载方法

Windows-User-Files-Mover 是便携软件，无需特殊的卸载过程。

### 卸载步骤

1. **删除程序文件**：
   - 手动删除解压的文件夹
   - 或使用文件管理器删除所有相关文件

2. **删除日志文件**（可选）：
   - 删除程序目录中的 `Windows_UserFiles_Mover.log` 文件

3. **删除备份文件**（可选）：
   - 删除之前创建的开始菜单备份文件夹
   - 注意：确保不再需要这些备份文件

4. **卸载Python**（仅Python版本）：
   - 如果不再需要Python环境，可以通过控制面板卸载Python
   - 注意：这可能会影响使用Python的其他程序

### 注意事项

- 卸载程序不会影响之前迁移的文件
- 已创建的目录联接仍将保持不变
- 如果需要恢复迁移的文件，必须手动执行相应操作
