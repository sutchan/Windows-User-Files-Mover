## 通用问题

### 1. 工具介绍

Windows-User-Files-Mover 是一个用于将 Windows 用户文件夹（如文档、下载、图片等）从系统盘移动到其他磁盘的工具，支持文件迁移、开始菜单备份和还原功能。

### 2. 版本区别

- 批处理版本（Windows_UserFiles_Mover.bat）：轻量级，无需安装，兼容性好，但界面简单。
- Python版本（Windows_UserFiles_Mover.py）：提供图形界面，操作更直观，功能更丰富，但需要Python环境或运行打包后的EXE文件。

### 3. 版本选择

- 如果您的系统没有安装Python，建议使用批处理版本。
- 如果您需要更友好的界面或额外功能，建议使用Python版本。

### 4. 最新版本

当前最新版本为 v1.12.0，支持所有主流 Windows 系统。
