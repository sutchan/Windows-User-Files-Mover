### Bug 修复：EXE 启动时 TclError "expected integer but got YaHei"
- 根因：`("Microsoft YaHei UI", 15, "bold")` 含空格字体名，PyInstaller 打包后 Tcl/Tk 解析 font tuple 时拆散参数。
- 第一次修复尝试：`_setup_style` 改用 `tkinter.font.Font` 对象 → 仍失败。
- **真正的根因**：`main()` 中 `root.option_add("*Font", "Microsoft YaHei UI 9")`，Tcl option database 将空格拆散为独立参数。
- 最终修复：彻底移除所有自定义字体——删除 `root.option_add`、删除 `_setup_style` 中所有 `font=`、删除 `import tkinter.font`。GUI 使用系统默认字体（Windows Segoe UI 效果良好）。
